# Finite C3 × C5 code verification and family application

Facts: The simple Cartesian graph C3 □ C5 has 15 vertices and degree 4. Define K_v=X_v∏_{u∼v}Z_u, S_even=⟨K_0K_v:v=1,…,14⟩, and Q=span{|G⟩,Z_all|G⟩}. The code stabilizer has binary symplectic rank 14, the graph stabilizer rank 15, and adjoining logical X=Z_all and logical Z=K_0 gives normalizer rank 16. Every stabilizer pair commutes; both logicals commute with every stabilizer and anticommute with each other. Phases are fixed by the actual commuting Hermitian graph generators, so no binary-rank inference is being used to choose signs.

Facts: For E represented by (x,z), its syndrome against K_0K_v is c_v+c_0 with c=z+Ax over F2. The independent standard-library enumerator tested identity, 45 weight-one errors, and 945 weight-two errors: exactly 991 syndromes, all distinct. Any nonidentity Pauli of weight at most 4 can be partitioned into two distinct errors of weight at most 2. A zero syndrome for their product would force a collision. Therefore every nonidentity normalizer Pauli has weight at least 5, establishing purity as well as distance at least 5. K_0 has weight 5 and is a nontrivial logical, so Q is exactly pure [[15,1,5]]. An additional increasing-weight search independently found minimum normalizer/logical weight 5; one witness is YYYYYIIIIIIIIII, supported on the first C5 row. Vertex order is lexicographic (a,b), b fastest, with the leftmost displayed Pauli on vertex 0.

Facts: Exact published overlap is present. Kovalev, Dumer, and Pryadko, [PRA 84, 062319 (2011)](https://link.aps.org/accepted/10.1103/PhysRevA.84.062319), Example 12 and Table I on PDF page 10, give a [[15,3,5]] CWS code whose graph generator is ZIZIIXIIZIZ and whose classical code consists of three length-five repetition blocks. The centered graph offsets are ±3 and ±5 modulo 15. Our checked permutation (a,b)↦5a+3b mod15 matches every adjacency entry. The three published classical basis words are 0x1249, 0x2492, 0x4924, whose XOR is 0x7fff. Thus our [[15,1,5]] is a literal subcode of the published code on the same graph, after permutation. The same paper's Example 6 already states graph distance 5 for square L×L tori with L≥5. The geometric D=2 instance is consequently not a new code construction.

Assumptions: The parent graph lane supplies a separate proof candidate that G_D=C3^(□(D−1))□C5 has graph-state distance 2D+1 for D≥3. This note does not independently audit that general combinatorial theorem. Conditional on it, the proposed repetition-word application is sound: for a Pauli of weight at most m=2D, wt(z+Ax)≤(m+1)wt(E)≤m(m+1)<N. Its classical image therefore cannot equal allones, while a zero image would contradict graph-state distance. This yields a pure [[N,1,m+1]] code, with exact distance witnessed by K_v. N=5·3^(D−1)>2D(2D+1) holds at D=3 (45>42) and inductively since 3·2D(2D+1)−2(D+1)(2D+3)=8D²−4D−6>0 for D≥2. The D=2 length criterion fails (15<20), so the exact finite test above supplies that case separately.

Facts: The conversion itself is directly covered by [Sudevan et al., arXiv:2405.06142v4](https://arxiv.org/html/2405.06142v4), Theorem 2: an m-uniform state on an m-regular graph combined with a classical linear code of distance greater than m(m+1) gives a pure quantum code of distance m+1. Its Proposition 2 retains the sufficient lattice side condition n_i≥8; Example 1 gives the familiar C5 repetition-word [[5,1,3]] code. Therefore, conditional on the graph theorem, the combined family has parameters [[5·3^(D−1),1,2D+1]], D≥1. This is an application of known CWS machinery, not a novel conversion principle. No claim of new general-family priority is established by this bounded search.

Recommendations: Present the verified D=2 instance as a known subcode and a reproducibility/base-case check. Any research claim should attach to the independently proved mixed-side graph-distance result and its consequences for geometric graph resources. As D varies, degree 2D and embedding dimension grow, distance is 3+2 log_3(N/5), and rate is 1/N; this is not a bounded-degree asymptotic claim or a fixed-dimensional locality claim. No encoder locality, best-code parameter, or hardware advantage is established.
